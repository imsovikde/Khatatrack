# 🛡️ Security Policy — KhataTrack

## Supported Versions

The latest version on the `main` branch and the official releases receive active security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes     |
| < 1.0   | ❌ No      |

## Reporting a Vulnerability

We take the security of **KhataTrack** very seriously. If you discover a security vulnerability or potential privacy issue:

1. **Do NOT open a public GitHub issue.**
2. Email **Souvik Dey** directly at [`imsovikde@gmail.com`](mailto:imsovikde@gmail.com) with the subject `[SECURITY] KhataTrack Vulnerability Report`.
3. Include details of the vulnerability, steps to reproduce, and any relevant proof of concept logs.

We will acknowledge receipt of your report within **48 hours** and provide regular progress updates regarding the fix.
