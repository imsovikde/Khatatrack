# 💬 Getting Support for KhataTrack

Need help with **KhataTrack**? Here are the recommended ways to get support:

---

## 🐞 Reporting Bugs & Issues

If you encounter bugs, unexpected app crashes, or broken behavior:
1. Check the [Existing Issues](https://github.com/imsovikde/Khatatrack/issues) to see if it has already been reported.
2. If not, open a new issue using our [Bug Report Form](https://github.com/imsovikde/Khatatrack/issues/new?template=bug_report.yml).

---

## 💡 Requesting Features

Have an idea to improve KhataTrack?
- Submit a [Feature Request Form](https://github.com/imsovikde/Khatatrack/issues/new?template=feature_request.yml) with your idea.

---
