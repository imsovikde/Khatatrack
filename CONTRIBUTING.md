# 🤝 Contributing to KhataTrack

Thank you for your interest in contributing to **KhataTrack**! We welcome contributions from developers of all skill levels.

---

## 🚀 Getting Started

1. **Fork the repository**: Click the `Fork` button at the top right of [imsovikde/Khatatrack](https://github.com/imsovikde/Khatatrack).
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/Khatatrack.git
   cd Khatatrack
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/my-awesome-feature
   ```

---

## 🛠️ Development Workflow

- Follow Kotlin official style guidelines.
- Ensure all tests pass before submitting your pull request:
  ```bash
  ./gradlew testDebugUnitTest
  ./gradlew lint
  ```
- Use clear, descriptive commit messages adhering to [Conventional Commits](https://www.conventionalcommits.org/):
  - `feat: add voice-to-text ledger entry`
  - `fix: resolve boot receiver alarm rescheduling crash`
  - `docs: update setup instructions in README`

---

## 📥 Submitting a Pull Request

1. Push your changes to your branch.
2. Open a Pull Request against the `main` branch of `imsovikde/Khatatrack`.
3. Provide a detailed description of your changes and reference any related issues.
